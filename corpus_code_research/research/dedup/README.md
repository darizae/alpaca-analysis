# Duplicate-Removal Code Notes

This folder contains the code used to study and remove duplicate recordings of the same alpaca hum.

A normal archive user should not start here. The final cleaned corpus is already included at:

`Published\Data\Corpus construction\cleaned_alpaca_hum_corpus`

Use this folder only if you need to inspect the duplicate-removal code or rerun the duplicate-removal experiments.

The final handoff result is the 28,561-call corpus, not the unfinished experiment folders inside this code tree.
